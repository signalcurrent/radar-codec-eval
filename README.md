# radar-codec-eval

Task-based evaluation harness for raw radar data compression — the
companion repository to:

> E. M. Chrabot, "Task-Based Evaluation of Raw Radar Data Compression: A
> Pre-Registered Study of Where Classical Codecs Fail to Preserve Target
> Detection, and Why," arXiv:2608.17269 [eess.SP], 2026.
> https://arxiv.org/abs/2608.17269

Radar codecs are usually evaluated with image-fidelity metrics (PSNR,
SSIM, SQNR). This repository scores them instead against what radar data
is collected to do: codecs are evaluated **after SAR focusing**, under a
**two-sided detection criterion** — a CFAR detection-agreement floor
*and* a false-alarm budget at matched threshold — using frozen task
models trained once on uncompressed data. The evaluation criterion,
physics predictions, and interpretation rules were **pre-registered**
before the corresponding data existed; the amendment and retraction
trail is preserved in `reports/FINDINGS.md` and in this repository's
commit history.

## What is in this repository

- **Evaluation harness** — 2-D CA-CFAR detection agreement
  (`radarcodec/tasks/cfar.py`), frozen-ATR pipeline
  (`radarcodec/tasks/atr.py`), radar quality metrics
  (`radarcodec/metrics/`).
- **Classical baselines** — Lloyd–Max BAQ, JPEG2000, HEVC, the
  fairness-audited plane mapping, and the exactly-invertible unitary
  dechirp/focus transform (`radarcodec/baselines/`), with its round-trip
  verification tests (`tests/test_roundtrip.py`).
- **Data readers** — Sentinel-1 Level-0 decoding, AFRL Gotcha GMTI phase
  history, MSTAR chips, and a synthetic scene generator
  (`radarcodec/data/`).
- **The complete results log** — `experiments/runs.jsonl`, append-only;
  every number and figure in the paper regenerates from it.
- **The pre-registration trail** — `reports/FINDINGS.md` (amendments,
  interpretation rules, one documented retraction) plus this
  repository's commit history with original timestamps.
- **Figures** — every figure in the paper, regenerated by
  `scripts/plot_curves.py` and `scripts/make_ringing_figure.py`.

## What is deliberately not in this repository

Per the paper's Reproducibility section, the learned codec's
**architecture implementation and trained weights are withheld**. That
component is reported in the paper only as a bounded negative result
under pre-registered interpretation rules, and it is proprietary; it is
not required to reproduce any classical result or to evaluate a new
codec against the criterion. Consequently:

- `scripts/eval_gotcha_neural.py`, `radarcodec/train.py`, and
  `configs/ae_gotcha.yaml` are released as cited in the paper but
  reference the withheld model module and will not run as published.
  Their hyperparameters disclose nothing beyond what the paper's
  Sections 5.7–5.8 state in prose.
- This repository was produced from a private working repository with
  `git filter-repo`: the withheld model paths and internal business
  documents were removed from all history, and **author/committer dates
  were preserved**, so the pre-registration chronology is intact.
  Programmatic (non-technical) notes in `reports/FINDINGS.md` are
  redacted with visible markers, and a small set of programmatic
  identifiers was replaced with `[redacted]` throughout the history's
  file contents; no technical content was altered. Commit hashes cited
  inside `reports/FINDINGS.md` refer to the private working repository;
  this mirror's hashes differ (dates are preserved).

## Quickstart: regenerate the paper's figures (no data downloads)

```bash
pip install -r requirements.txt
python scripts/plot_curves.py       # rate-vs-utility figures from runs.jsonl
python tests/test_roundtrip.py      # transform invertibility verification
```

Both work from a fresh clone with no radar data present, because the
results log and the transform tests are self-contained.

## Reproducing the evaluations from raw data

The datasets are **not redistributed** here; each is obtained from its
authoritative source:

| Dataset | Source | Access |
|---|---|---|
| Sentinel-1 Level-0 (stripmap RAW) | Copernicus / ASF (`scripts/download_s1.py`) | Free Earthdata account |
| AFRL Gotcha GMTI Challenge Problem | AFRL SDMS (sdms.afrl.af.mil) | Free registration. Approved for public release, distribution unlimited: Public Release # 88 ABW-09-0967 (data), # 88 ABW-09-1031 (paper) |
| MSTAR public target chips | AFRL SDMS | Free registration |

With data in place: `scripts/eval_focused.py` (Sentinel-1 sweep),
`scripts/eval_gotcha.py` (Gotcha raw + transform-domain sweeps),
`scripts/eval_atr.py` (MSTAR frozen-ATR sweep). The HEVC baseline
requires an ffmpeg binary with libx265 on PATH.
